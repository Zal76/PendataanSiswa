## Deskripsi
Sistem Manajemen Data Siswa adalah aplikasi berbasis web untuk mempermudah pengelolaan informasi siswa di sekolah, seperti biodata, nilai, dan kehadiran. Aplikasi ini membantu guru dan admin dalam memonitor data siswa secara cepat dan terstruktur.

Fitur utama:
- Input dan update data siswa
- Manajemen nilai dan absensi
- Pencarian dan filter data siswa
- Tampilan dashboard yang intuitif

---

## Tools yang Digunakan
- **Frontend:** HTML, CSS,
- **Backend:** PHP, 
- **Database:** MySQL  
- **Tools:** VS Code, Git, GitHub

## Instalasi
git clone https://github.com/Zal76/PendataanSiswa.git
cd Spk_Pemilihan_Bimbel
composer install
cp .env.example .env
php artisan key:generate
php artisan serve
